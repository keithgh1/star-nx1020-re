# NX-1020 - Deliverables

Final outputs from the Star NX-1020 font-ROM reverse-engineering. Build sources and scripts are
in `../work/`; narrative documentation is in `../docs/`.

## Interactive ROM map
- **ROM_MAP.html** - a self-contained, clickable map of ROM1 (128 KB) + ROM2 (32 KB): columns
  per ROM/bank, regions color-coded by category (firmware / system code / pointer & descriptor
  tables / font metrics tables / glyph bitmaps per font / text), with an offset-sorted contents
  sidebar and a detail panel. Font regions link to their glyph sheet. (Interactive companion to
  `../docs/ROM_MAP.md`; cross-links to FONT_CATALOG.html.) Rebuild: `work/build_rommap.py`.

## Font catalog
- **FONT_CATALOG.html** / **FONT_CATALOG.pdf** - self-contained catalog of the resident fonts:
  the 5 typefaces (Draft, Courier, Sanserif, Orator, Script) plus the additional 8-dot faces
  (Draft Elite, the two High-Speed Draft faces) and extended-character sets, each with a full
  glyph sheet and metadata.

## Glyph sheets (full character sets, rendered by the one generic box-grid engine)
- **FONT_draft.png** - Draft, Pica (10 cpi, 9×11), 8-dot.
- **FONT_courier.png / FONT_sanserif.png / FONT_orator.png / FONT_script.png** - the four 16-dot NLQ faces.
- **SET_8dot_pica_132C1.png** - Draft Pica (bounded view; same data as FONT_draft).
- **SET_8dot_elite_12B91.png** - Draft Elite (12 cpi, 9 columns).
- **SET_8dot_hs_pica_14509.png** - High-Speed Draft Pica (10 cpi, 9 columns - HS-Draft's own
  stored face, drawn sparse for speed).
- **SET_8dot_hs_elite_13DE1.png** - High-Speed Draft Elite (12 cpi, 7 columns; previously
  mislabeled "Condensed" - condensed printing is a programmatic transform, not a stored face).
- **SET_8dot_accent_13129.png** - Draft accented upper-half companion (no alphabet of its own).
- **SET_8dot_boxgfx_13851.png** - Draft box-graphics + upper-half companion (no alphabet; index-labeled).

## Analysis
- **rom1_coverage.png** - ROM1 coverage map (glyph-bitmap extraction ≈ 88%; rest = firmware,
  system code, and metrics/descriptor/pointer tables).
- **sample_fn3_draft.png** - text-rendering parity output (reproduces the FN3 reference scan).

## Firmware call graph (ROM2 v3.2, device M50734)
Generated by the `m740dasm` fork's report mode (`m740dasm -c nx1020.m740 --json` / `--call-graph`):
635 routines, 3004 static call edges, 3 computed (indirect) dispatch sites.
- **nx1020_callgraph.txt** - full human-readable call graph (each routine's callees `->` and callers `<-`).
- **nx1020_report.json** - machine-readable model (`m740dasm-report/1`): routines, call edges,
  vectors, symbols, and a full cross-reference map.
- **nx1020_printpath.png / .svg** - focused diagram of the print path (line buffer → glyph fetch →
  column→head-pin format → head fire), with edges pulled from the JSON model.
- **nx1020_printpath.dot** - Graphviz source for the print-path diagram. Regenerate from the JSON
  with `work/gen_printpath_dot.py`, then `dot -Tpng nx1020_printpath.dot -o nx1020_printpath.png`.
