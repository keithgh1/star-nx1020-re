Star NX-1020 — Resident Font Catalog

Five resident typefaces recovered from the printer's font ROM, with bitmaps and metadata.  ·  Interactive ROM map ▸

Source: ROM1 (IC7, D27C1001, 128 KB font/data ROM)  ·  firmware ROM2 v3.2 (32 KB)  ·  CPU Mitsubishi M50734

The NX-1020 is a 9-pin impact dot-matrix printer. Its resident fonts are fixed-size bitmaps stored in a 128 KB ROM, read through a gate array via a banked window. Each face has an 8-byte-per-character metrics table (in ROM bank 2) pointing at the packed glyph bitmaps (in banks 0/3). Draft glyphs are 8 dots tall (single pass); the four near-letter-quality faces are 16 dots tall (two half-dot-offset passes, planar-interleaved). All offsets below are file offsets into the ROM1 image.

Additional 8-dot sets — Draft pitches & extended characters

The Draft card above is Pica (10 CPI, 9×11). The 8-dot region of the ROM is a run of complete CP437 Draft faces at different pitches (each carries the full alphabet + accented/extended characters), interleaved with shared companion sets (accented upper-half and box-graphics) that have no alphabet of their own. Each sheet below is bounded to one set. (Bold/double-strike/expanded etc. remain programmatic, not stored.)

High-Speed Draft — Pica (10 CPI) 8-dot · ALPHABET face · max 9 cols · group 1, pica slot

Format legend. 8-dot draft: column-major, 1 byte/column, bit 7 = top pin, proportional width. 16-dot NLQ: planar-interleaved — first h bytes = even rows (0,2,…,14), next h = odd rows (1,3,…,15), where h = width/2 columns at half horizontal pitch. Width = pointer difference between consecutive characters.

Notes. Bold / condensed / double-width / double-strike / super-subscript and (for the upright faces) italic are produced programmatically by the firmware, not stored as separate glyphs — Script is the only inherently cursive design. Selection codes are the ESC/P ESC k typeface numbers; the internal descriptor indices differ.
